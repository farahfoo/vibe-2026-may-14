
# Project Blueprint

## Overview

This project is a simple web application that demonstrates the use of modern web technologies, including Web Components, to create interactive UI elements.

## Implemented Features

### Initial Setup
- **`index.html`**: Basic HTML structure.
- **`style.css`**: Basic stylesheet.
- **`main.js`**: Basic JavaScript file.

### Toto Number Generator
- A Web Component that generates 6 unique random numbers (1-49).
- A button to generate an additional unique number.
